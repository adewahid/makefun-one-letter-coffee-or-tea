My entry for the [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) competition on make.fun: exactly one letter, **A** — coffee.

## Entry

`main.ts` writes exactly one byte, `A`, to `/output/entry.txt` — A for coffee, nothing else: no word, no explanation, no punctuation, no trailing newline.

Run it with Node 22:

```sh
node main.ts
```
